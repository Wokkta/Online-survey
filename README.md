# Survey App — React + TypeScript + Vite

Минималистичное приложение опроса с использованием React, TypeScript и Vite. Структура разделяет бизнес-логику и отображение, упрощая масштабирование.

## 🚀 Запуск проекта

```bash
# Установка проекта
git clone https://github.com/Wokkta/Online-survey.git

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка проекта
npm run build

## 🔧 Дополнительно

* Проект не использует сторонние UI/библиотеки
* Стили отделены или могут быть отделены
* Для мобильного UI можно заменить `ui/`компоненты
```
